# Commissary Ordering Tool handoff

The complete reusable operating contract is published in the validated Supabase record `platformMetadata|operations|current`: fixed departing unit, receiving cafes/profit centers, all order items with costs/units/G/Ls, delivery definitions, cutoff, quantity increment, order-unit version, and the Transfer Tool handoff. Orders and prep progress remain separate records. The legacy Commissary metadata row remains readable for backward compatibility; the shared operational record is primary. Operational metadata version 17 adds the reviewed six-week Global recipe-output policy, including nested preparation resolution and explicit in-unit exceptions.

Global ordering resolves reviewed nested recipe preparations before using direct ingredients. Raw in-unit proteins are removed only after the recipe tree is evaluated, so hidden marinades, sauces, rubs and seasonings remain available to both Prep Lists and generated transfers. Week 3 excludes Pork Brine MRN `60487`; Week 6 Kielbasa MRN `5365.6` is entirely in-unit. Porto exposes two optional sauce slots, including Piri Piri Dipping Sauce MRN `120722` and Piri-naise Dipping Sauce MRN `121071`. Existing saved orders are normalized without rewriting their Supabase rows.

The Draft Commissary Ordering Tool stores one shared Supabase order per receiving cafe and service week. Commissary (`SEA20 Cricket`, profit center `22472`) is the fixed departing unit.

- Salad Bar ordering uses a service-week effective-date boundary. Weeks before 2026-11-16 retain the original 41-item roster and original costs; `MenuWorks SB Gallon Convert 3.0.xlsx` becomes authoritative beginning 2026-11-16. Beginning with metadata version 15, Alex's reviewed package overrides make Spring Mix a 3-pound bag at $7.75, Arugula a 4-pound bag at $17.80, Chopped Kale a 2.5-pound bag at $8.81, Cottage Cheese a 5-pound container at $14.15, Blue Cheese a 5-pound bag at $16.79, Feta a 5-pound bag at $15.89, and Cheddar a 5-pound bag at $13.60. The Transfer Tool exposes the current records under `Commissary Salad Bar`.

- `Generate transfer` sits below `Save shared order` and exports the current on-screen quantities, including unsaved edits, without writing an order record.
- `Generate Prep List` is available with the active order and combines the current on-screen cafe quantities with other saved cafe orders for that week. The Power Automate input and calculation fields are preserved on a separate tab that is hidden automatically. Visible Friday, Monday, and Wednesday cafe-delivery-map tabs use the shared delivery schedule. Every sheet retains the approved Audit-project workbook treatment: navy title/header bands, pale-blue grouped rows, stronger group-start rules, complete cell borders, Arial type, frozen headers, filters, and retained currency formatting.
- Locked weeks retain the combined Prep List and one exact-template S4 transfer workbook per cafe.
- `Prep List View` is a sibling tab to `Cafe Orders`. It defaults to the most recently locked production week and displays separate Friday, Monday, and Wednesday vertical, touch-first work lists. Each row shows the rolled-up quantity and unit prominently with the smaller per-cafe breakdown directly beneath it. A 600 ms hold toggles a completion check on touch devices; mouse and keyboard activation remain immediate.
- Prep completion is shared in Supabase as one `Commissary Prep Progress` record per service week (`commissaryOrder|prepProgress|<weekStart>`). Friday, Monday, and Wednesday item-id arrays remain independent. The storage boundary rejects unknown/duplicate items, unexpected delivery keys, invalid identities, and writes before cutoff; browser localStorage is not used.
