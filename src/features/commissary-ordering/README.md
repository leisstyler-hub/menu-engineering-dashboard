# Commissary Ordering Tool handoff

The complete reusable operating contract is published in the validated Supabase record `platformMetadata|operations|current`: fixed departing unit, receiving cafes/profit centers, all order items with costs/units/G/Ls, delivery definitions, cutoff, quantity increment, order-unit version, and the Transfer Tool handoff. Orders and prep progress remain separate records. The legacy Commissary metadata row remains readable for backward compatibility; the shared operational record is primary.

The Draft Commissary Ordering Tool stores one shared Supabase order per receiving cafe and service week. Commissary (`SEA20 Cricket`, profit center `22472`) is the fixed departing unit.

- Salad Bar ordering is sourced from the reviewed `MenuWorks SB Gallon Convert 3.0.xlsx` 41-row cost index. Exact source Item Cost, Waste %, Item + Waste Cost, MRN and source portion are persisted in operational metadata version 11 for cross-tool use. Gallon/128-floz rows order in 0.25-gallon increments; six explicit 3-pound packs order as whole containers. The Transfer Tool exposes the same records under `Commissary Salad Bar`.

- Friday delivery covers Monday service, Monday delivery covers Tuesday–Wednesday service, and Wednesday delivery covers Thursday–Friday service.
- Receiving cafes and delivery definitions resolve from validated shared `Commissary Metadata` (`commissaryOrder|metadata|current`) in Supabase. The exact release configuration is retained as a code fallback for a read outage; current receiving cafes are SEA39 Nessie, SEA20 Cricket, and SEA27 Dawson.
- The server and browser lock a service week at 5:00 PM `America/Los_Angeles` on the prior Wednesday.
- Active gallon/128-floz items use gallon bags in 0.25-gallon increments; explicit 3-pound source rows use whole 3-pound containers. Existing retired rows remain readable in historical orders and exports.
- Item `Requires ...` and `New recipe` notes remain internal catalog/Prep List production guidance and are not rendered in the chef-facing ordering grid.
- `Generate transfer` sits below `Save shared order` and exports the current on-screen quantities, including unsaved edits, without writing an order record.
- `Generate Prep List` is available with the active order and combines the current on-screen cafe quantities with other saved cafe orders for that week. Its workbook opens on a consolidated prep-list tab whose first columns are Ingredient / item, Total quantity, and Order unit, followed by the existing production-detail fields. The Power Automate input and calculation fields are preserved on a separate tab that is hidden automatically. Visible Friday, Monday, and Wednesday cafe-delivery-map tabs use the shared delivery schedule. Every sheet retains the approved Audit-project workbook treatment: navy title/header bands, pale-blue grouped rows, stronger group-start rules, complete cell borders, Arial type, frozen headers, filters, and retained currency formatting.
- Locked weeks retain the combined Prep List and one exact-template S4 transfer workbook per cafe.
- `Prep List View` is a sibling tab to `Cafe Orders`. It defaults to the most recently locked production week and displays separate Friday, Monday, and Wednesday vertical, touch-first work lists. Each row shows the rolled-up quantity and unit prominently with the smaller per-cafe breakdown directly beneath it. A 600 ms hold toggles a completion check on touch devices; mouse and keyboard activation remain immediate.
- Prep completion is shared in Supabase as one `Commissary Prep Progress` record per service week (`commissaryOrder|prepProgress|<weekStart>`). Friday, Monday, and Wednesday item-id arrays remain independent. The storage boundary rejects unknown/duplicate items, unexpected delivery keys, invalid identities, and writes before cutoff; browser localStorage is not used.
- Global ordering uses one weekly cycle menu, up to three entrees and four sides. Recipe sub-components are automatic. Global record version 2 rejects cross-menu selections and quantities for items outside the selected slots.
- Prep List View is grouped and jumpable by Salad Bar, Deli, Grill and Global. Sauce units convert to cups/quarts/gallons only from explicit volume units; weight units remain untouched.
- `Packout Packet` produces a letter-size PDF grouped by cafe, delivery and station. Its canonical payload is saved first as hidden Supabase record `commissaryOrder|packoutPacket|<weekStart>`; no email or scheduled sender is configured.
- The Spanish switch translates all current commissary item names, categories, supported order units and Prep View interface labels from a bundled reviewed dictionary. Future untranslated catalog values fall back to English, while verification requires complete coverage of the current catalog.
- Green Peas MRN `62341` cost `$9.455573` per gallon and classify on `4111009 — Frozen`; other active Salad Bar items use `4111011 — Prepared Foods`. The retired Frozen Peas MRN `4877` row remains readable only for historical orders.
- Global ordering begins Cycle Week 1 on Monday 2026-11-16 and repeats every six weeks: Porto/Taco Total, Lemongrass + Lime/Chiang Mai, Anisa/Cypress, Balti/Naan Nomad, Lotus/House of Teriyaki, and Smokehouse BBQ/Roam BBQ. Chefs choose one weekly menu, then may order up to three entrees and four sides as whole finished-item portions; extensions are excluded.
- The Global roster and recipe-quantity projection are generated from the live Supabase menu catalog plus reviewed Balti, House of Teriyaki and Smokehouse recipe packs. Live Supabase Item + Waste cost remains authoritative for each finished-item S4 transfer line; the Prep List expands exact ingredient and sub-recipe quantities without exposing recipe methods.
- Cricket, Nessie and Dawson Global prep routes to the Cricket hub. Global prep for Bingo, Grace, Sonic, Blueshift, Everest, Gemini and Astra routes to Blueshift. Sonic receives no Global prep.
