# Commissary Ordering Tool handoff

The Draft Commissary Ordering Tool stores one shared Supabase order per receiving cafe and service week. Initial receiving cafes are Nessie and Cricket. Commissary (`SEA20 Cricket`, profit center `22472`) is the fixed departing unit.

- Monday delivery covers Monday–Wednesday service; Wednesday delivery covers Thursday–Friday service.
- The server and browser lock a service week at 5:00 PM `America/Los_Angeles` on the prior Wednesday.
- Items formerly ordered by quart now use gallon bags in 0.25-gallon increments, with gallon cost equal to four times the former quart cost. Existing unversioned saved orders are converted from quarts to gallons at read time; new records carry `orderUnitVersion: 2`. Dressings retain the workbook's stated specialty container where applicable: 5-liter container for Balsamic Vinegar and 32-ounce bottle for Fat Free Italian.
- Item `Requires ...` and `New recipe` notes remain internal catalog/Prep List production guidance and are not rendered in the chef-facing ordering grid.
- `Generate transfer` sits below `Save shared order` and exports the current on-screen quantities, including unsaved edits, without writing an order record.
- `Generate Prep List` is available with the active order and combines the current on-screen cafe quantities with other saved cafe orders for that week. Its workbook opens on a consolidated prep-list tab whose first columns are Ingredient / item, Total quantity, and Order unit, followed by the existing production-detail fields. The Power Automate input and calculation fields are preserved on a separate tab that is hidden automatically. The visible Monday and Wednesday cafe-delivery-map tabs are unchanged. Every sheet retains the approved Audit-project workbook treatment: navy title/header bands, pale-blue grouped rows, stronger group-start rules, complete cell borders, Arial type, frozen headers, filters, and retained currency formatting.
- Locked weeks retain the combined Prep List and one exact-template S4 transfer workbook per cafe.
- `Prep List View` is a sibling tab to `Cafe Orders`. It defaults to the most recently locked production week and displays separate Monday and Wednesday vertical, touch-first work lists. Each row shows the rolled-up quantity and unit prominently with the smaller per-cafe breakdown directly beneath it. A 600 ms hold toggles a completion check on touch devices; mouse and keyboard activation remain immediate.
- Prep completion is shared in Supabase as one `Commissary Prep Progress` record per service week (`commissaryOrder|prepProgress|<weekStart>`). Monday and Wednesday item-id arrays remain independent. The storage boundary rejects unknown/duplicate items, unexpected delivery keys, invalid identities, and writes before cutoff; browser localStorage is not used.
- The Spanish switch translates all current commissary item names, categories, supported order units and Prep View interface labels from a bundled reviewed dictionary. Future untranslated catalog values fall back to English, while verification requires complete coverage of the current catalog.
- Frozen Peas replace Blanched Green Beans at MRN `4877` and `$9.08` per gallon (the former `$2.27` per quart). Existing saved quantities under the retired green-bean item id are read into the new peas slot and converted to gallons, and generated S4 transfers classify the peas line on `4111009 — Frozen`; all other commissary items retain `4111011 — Prepared Foods`.
- S4 exports consolidate both deliveries to one row per item, cover the Friday–Thursday accounting period, use the receiving cafe profit center, and apply the approved Prepared Foods G/L fallback (`4111011`).
- Aleppo-Edamame uses MRN `176736` per the requesting admin.
